## О проекте

Программа «Статистический анализатор данных опросов» предназначена для обработки и анализа числовых результатов социологических опросов. Реализована на языке C# с использованием WPF (.NET 8) и разметки XAML.

Все алгоритмы реализованы **самостоятельно** — без использования встроенных библиотечных функций (`Array.Sort`, `Enumerable.Average` и т.п.), выполняющих ту же задачу.

---

## Возможности

- Генерация случайных данных опроса (от 10 до 100 000 значений, диапазон оценок от 1 до 10).
- Вычисление статистических характеристик:
  - среднее арифметическое;
  - медиана;
  - мода (с поддержкой мультимодальных распределений);
  - дисперсия;
  - стандартное отклонение;
  - минимум и максимум.
- Сортировка данных алгоритмами **QuickSort** и **MergeSort** с замером времени через `Stopwatch`.
- Поиск аномалий методом межквартильного размаха (**IQR**).
- Визуализация данных:
  - гистограмма распределения;
  - ящик с усами (Box Plot);
  - диаграмма рассеяния.
- Копирование результатов в буфер обмена и сохранение в текстовые файлы.
- Всплывающие подсказки (ToolTip) и окно справки для пользователя.
