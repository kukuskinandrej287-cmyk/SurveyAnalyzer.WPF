## 📌 О проекте

Программа «Статистический анализатор данных опросов» предназначена для обработки и анализа числовых результатов социологических опросов.

**Все алгоритмы реализованы самостоятельно** — без использования встроенных библиотечных функций (`Array.Sort`, `Enumerable.Average` и т.п.).

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🎲 Генерация данных | Случайные оценки от 10 до 100 000 значений, диапазон 1–10 |
| 📈 Статистика | Среднее, медиана, мода, дисперсия, стандартное отклонение, минимум, максимум |
| 🔀 Сортировка | QuickSort и MergeSort с замером времени (Stopwatch) |
| ⚠️ Аномалии | Поиск выбросов методом межквартильного размаха (IQR) |
| 📊 Визуализация | Гистограмма, ящик с усами (Box Plot), диаграмма рассеяния |
| 💾 Экспорт | Копирование в буфер обмена, сохранение в текстовые файлы |
| ❓ Справка | Всплывающие подсказки (ToolTip) и окно справки |

## 🧮 Реализованные алгоритмы

| Алгоритм | Метод | Сложность |
|---|---|---|
| Среднее арифметическое | `Mean()` | O(n) |
| Медиана | `Median()` | O(n log n) |
| Мода | `Mode()` | O(n) |
| Дисперсия | `Variance()` | O(n) |
| Стандартное отклонение | `StandardDeviation()` | O(n) |
| Быстрая сортировка | `QuickSort()` | O(n log n) средн. |
| Сортировка слиянием | `MergeSort()` | O(n log n) |
| Поиск аномалий (IQR) | `FindOutliers()` | O(n log n) |
